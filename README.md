# Itahari International School Management System

Complete school management system with Django REST Framework backend and React frontend.

## 🚀 Quick Start

### Backend (Django API)
```bash
cd backend
npm run dev
```
Backend runs on: http://127.0.0.1:8000/

### Frontend (React App)
```bash
cd frontend
npm start
```
Frontend runs on: http://localhost:3001/
