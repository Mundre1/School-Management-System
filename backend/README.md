# Smart School ERP System

Full-stack School Management System built with Django REST Framework and React.js

## Quick Start

### Backend
```bash
cd backend
source venv/bin/activate
python manage.py runserver
```

### Frontend
```bash
cd frontend
PORT=3001 npm start
```

### Login
- Email: admin@school.com
- Password: admin123

### Access
- Frontend: http://localhost:3001
- Backend API: http://localhost:8000
- Admin Panel: http://localhost:8000/admin

## Tech Stack
- **Backend:** Django 4.2.7, Django REST Framework, SQLite
- **Frontend:** React.js, React Router, Recharts, Axios
- **Authentication:** JWT

## Features
- Authentication & Authorization
- Students Management (Full CRUD)
- Staff Management
- Attendance Tracking
- Fee Management
- Results Management
- Dashboard with Analytics
