# Quick Start Guide

## 🚀 Run the Project

```bash
./run.sh
```

## 📍 Access URLs

- **Frontend:** http://localhost:3001
- **Backend API:** http://localhost:8000
- **Admin Panel:** http://localhost:8000/admin

## 🔑 Login Credentials

- **Email:** admin@school.com
- **Password:** admin123

## ✅ Working Features

1. **Dashboard** - Analytics, charts, timetable, events
2. **Students** - Add, view, edit, delete students
3. **Staff** - View staff members
4. **Attendance** - Track attendance by date
5. **Fees** - Payment tracking and statistics
6. **Results** - Exam results with grades

## 🛠️ Manual Setup

### Backend
```bash
cd backend
source venv/bin/activate
python manage.py runserver
```

### Frontend
```bash
cd frontend
PORT=3001 npm start
```

## 📦 Tech Stack

- Django 4.2.7 + Django REST Framework
- React.js + React Router + Recharts
- SQLite Database
- JWT Authentication
